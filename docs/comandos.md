# Comandos Utilizados

Atualizar Linux

```bash
sudo yum update -y
```

Ubuntu

```bash
sudo apt update
```

Verificar usuário

```bash
whoami
```

Ver IP

```bash
ip addr
```

Ver disco

```bash
df -h
```

Ver memória

```bash
free -m
```

Ver utilização CPU

```bash
top
```

Conectar SSH

```bash
ssh -i chave.pem ec2-user@IP
```
