# Conceitos Fundamentais

## EC2

Serviço de computação em nuvem da AWS.

## AMI

Imagem utilizada para criar uma instância.

## Key Pair

Par de chaves utilizado para autenticação SSH.

## VPC

Rede virtual privada onde as instâncias são criadas.

## Elastic IP

Endereço IP público fixo.

## EBS

Disco persistente utilizado pelas instâncias EC2.

## IAM

Serviço responsável pelo gerenciamento de usuários e permissões.

## CloudWatch

Serviço de monitoramento da AWS.
