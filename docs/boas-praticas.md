# Boas Práticas

## Segurança

- Utilizar MFA
- Nunca utilizar usuário Root
- Criar usuários IAM
- Utilizar Security Groups restritivos

## Custos

- Desligar instâncias quando não utilizadas
- Utilizar Free Tier sempre que possível
- Monitorar gastos no AWS Billing

## Disponibilidade

- Criar Snapshots
- Utilizar múltiplas zonas de disponibilidade
- Criar AMIs antes de mudanças importantes
